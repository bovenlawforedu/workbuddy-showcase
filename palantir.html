Palantir 方法论 → AI Native 产品设计

系统拆解 Palantir 的核心工作方法论，并把它映射成 AI Native / Agent 产品设计的四层同构框架，同时与当下流行的 Zero-Token Design 建立理论同构。

OntologyFDE 冷启动Zero-Token

核心洞察（一句话）

好的 AI Native Agent = Palantir Ontology（世界模型）+ FDE（冷启动）+ 受控 Action（安全边界）+ Zero-Token 哲学（把确定性留给系统，把判断留给模型）。

四层映射（面试重点）

Palantir 原版AI Native 翻译
本体论 OntologyAgent 的持久「世界模型 / 状态层」，非每次重塞 prompt
前置部署工程师 FDEAgent 的「冷启动 / onboarding」：人机共建 → 收敛自动化
Action + 权限Tool-calling 的「安全边界」：受控动作，带权限/溯源/可撤回
人类在回路 HITL按风险分级的「人审闸门」

与 Zero-Token Design 的同构

把「确定性、可预计算」从 LLM 身上剥掉，模型只做不可替代的最小判断——Ontology 就是把「世界是什么样」固化成结构化状态，让日常调用 token 趋近于零。

面试话术示例

「我用 AI Agent 把 Palantir 的 Ontology / FDE 方法论映射到 AI Native 产品设计，并与 Zero-Token Design 建立同构。核心理念是『让模型当调度员而非 root，世界长在外部结构化状态里，安全边界由受控 Action 定义』。完整推导在作品集里。」
