两段核心经历

第一段：从电商运营到跨境贸易，练出全流程交付能力。

做过电商运营、新媒体广告营销，签过 300+ 抖音 / 快手 KOL，管理过 5000 万+ 曝光；后来做跨境贸易，玩具 / 电子 / 家居类目合同金额近 140 万美金。这段经历让我理解一件事是怎么从需求、采购、履约、回款全链路跑下来的。边界条件是汇率波动、供应商交期、客户账期，每个变量都能让项目死在中途。我养成一个习惯：开工前先列出所有可能让项目卡住的点，再决定要不要接、怎么接。

第二段：从室内设计商务到独立顾问，练出跨角色协调能力。

做过高端别墅设计工程商务，面对长周期、多角色（业主、设计师、施工方、供应商）、高客单价项目。这里最大的挑战不是技术，是信息同步和预期管理。我学会在各方信息不一致时，先把真实约束拍在桌面上，再推动下一步。这个能力直接迁移到我后来做 AI 项目：先和客户把数据边界、决策权限、失败成本对齐，再动手。

我的工作方式

我做 0-1 产品的节奏是：需求 → 假设 → 原型 → 验证 → 放大。不会先憋一份完整 PRD，而是先花 2 小时搭一个能跑的最小闭环，证明有价值再继续。

我的工具箱

AI 编程

Cursor / Claude Code / Codex，用自然语言 + 代码把想法落成可运行原型。

Agent 与工作流

LLM、Tool Use、工作流编排、提示词工程，把重复步骤交给 Agent。

原型与体验

可交互原型、Figma、信息结构设计、文案与反馈细节。

工程基础

Python / JavaScript / TypeScript、API 调用、Git、本地部署与云端切换。

关于「复用」的纪律：项目之间相互独立；能跨项目复用的只有方法论逻辑（如"把设计语言沉淀成库+关键时调用适配"），绝不复用具体细节——风格、客户画像、客户需求等。换项目必须重新进现场定义其专属细节。
