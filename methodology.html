方法论认知 · 来自知识库「HA7CH · Lawted」的实践内化

我对 FDE / ANC 的理解

这一部分不是背书，而是我把 Lawted / HA7CH 的 FDE 体系内化成自己的实践形态。面试官看项目样本看的是"会不会做"，看这一页看的是"懂不懂底层"——这两件事要分开证明。

OP-ANCmicro-Sprint五层治理数据安全四档

1. FDE 到底是什么（我的定义）

来自 HA7CH / Lawted 体系的核心判断：FDE 不是"进客户现场写代码"，而是进现场找到真实业务点，把 AI 嵌进企业的运行层。麦肯锡把 AI 当"董事会要新增的核心议程"，而 ANC 的判断更彻底——AI 最终不是议程，是企业未来的新运行系统（Context + Skills + 权限 + 审计 + 反馈）。

所以 FDE 的交付物是能跑的系统，不是方案文档；FDE 的现场感来自"有隐私约束、有真实噪声、不给你 SDK、还催你出结果"的真实环境。

2. 我的实践形态：OP-ANC（一人公司版 ANC）

Lawted 跑的是 team-level ANC（多 ANP 协作、48 小时驻场、客户付 5–50 万）。我不照搬，而是把它缩放到"一人体 + <5 小时/周"的现实约束——我把它叫 One-Person ANC（OP-ANC）。几个关键再定义：

Lawted 原概念我的缩放为什么
48 小时驻场 Sprint4 小时周末 micro-Sprint我没有驻场条件，但节奏逻辑相同：先找到真实业务点
多 ANP 组织成公司自我 / 客户 / 家庭 三套 context，共用一套 skill 库我只有一个人，但跨域复用同一套 skill
飞轮：知识→Skill→自动化私有经验→可复用 Skill→下次 10× 快交付的副产品是 skill，复用降低下次成本
团队规模 / 产线关键指标 = skill 复用次数一人公司不看团队规模，看资产是否真被复用
企业级 50 万合同几千–几万小单也合理早期客户愿付少，这是阶段，不是降级
我不做 AI 培训 / 训练营（那是 HA7CH 在做的），我是实操者不是 KOL。我也不硬上"48 小时 Sprint"——节奏不匹配会崩。OPC（一人公司）本身就是董事会 + 管理层 + 一线，所以我用"确认当前在哪个阶段"替代"选一种定位"。

3. 我的交付节奏：micro-Sprint（≤5hr/周）

把 48 节奏缩放到个人：48 小时验证 → 48 天形成能力 → 48 周重构公司。我的版本：

周动作产出
第 1 周（2hr）48 小时验证：选一个真实业务点，跑通 AI 辅助全流程验证报告：原耗时 vs AI 耗时、字段可用率、人工修正项
第 2 周（2hr）48 天起步：把验证沉淀为 Context + Skill + 反馈可复用 Skill 模板 + Agent 权限边界清单
第 3–4 周（1hr/周）48 天深化：在第二个业务点复用，验证跨场景修正率是否下降、交付速度是否提升

4. 五层治理（压缩版，接单即生效）

层对我意味着落地动作
Context 治理知识资产边界明确哪些客户资料可进外部模型、哪些必须留本地 / 专属环境
Skills 治理交付方法论把反复出现的交付步骤封装为 Skill 模板，保留版本记录
Agent 权限Agent 能替我做什么细化到：能读哪些文档、调哪些系统、发哪些消息、多少钱以下自动执行
责任治理我是 Owner + DRIAI 辅助决策，但我对客户交付负最终责任——这条不能外包给 AI
异常升级止损机制关键交付前必须人工确认；异常输出必须回滚；敏感数据泄露立即响应

5. 数据安全：四档菜单 + 我的默认档位

核心原则：数据安全不是判断题（安不安全），是工程选型题（怎么运）。进现场前你甚至不知道要保护什么——正确顺序是先找到任务，再定数据。我接单的标准动作：第一次沟通就问客户"数据能否出境、能否上云、有无行业合规要求"，再从四档菜单选一档，把成本 / 周期 / 能力差异讲清楚，写进工作说明书。

项目我的默认档位
数据存储境内云（第二档）：客户资料用 ima / 腾讯云等境内服务，不存境外
模型算力境内模型为主；如客户允许用 Claude / GPT，切换但告知客户
日志训练关闭数据训练：所有模型 API 调用关闭"用于训练"
客户敏感数据本地处理：财务数据、合同条款等敏感内容在本地环境，不进云端模型
权限最小权限：Agent 只能读任务相关数据，不能访问其他客户资料

6. 三组指标自检（每次交付后问自己）

维度自检问题
能力积累上次交付的 Context 和修正，有没有沉淀成 Skill？同样的活下次能不能更快？
治理Agent 权限边界写清楚了吗？关键交付节点有我的人工确认吗？
组织结构有没有因为 AI 减少不必要的协调？决策是不是更接近客户现场了？
与作品集的关系：上面 8 个样本，每一个都是这套认知的"现场演练"——谈话录音系统对应 Context / 责任治理与数据安全；测评 MVP 瘦身对应"能力积累"与删冗余；抖音 / 玩具调研对应 Echo 与"进现场"。认知与实践是一体的。
