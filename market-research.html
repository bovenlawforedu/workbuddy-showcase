FDE · 行业调研 + 数据诊断

零售 / 玩具市场调研

扎进零售和玩具行业一线，用公开情报加真实订单数据，搭出一条"审计→指标→报告"的管道，把那种"市场感觉"变成一套能复用、能更新的情报系统——这正是 FDE 说的"进现场 + 部署能跑的系统"。

进现场摸数据数据诊断可复用管道

1. 两个并行子项目

  • 益智玩具跨平台调研：国内（天猫/京东/抖音/小红书/1688）+ 跨境（Amazon / TikTok Shop）的选品、用户评价、竞品、趋势。
  • 电商业务健康度分析：用 UCI Online Retail 真实订单数据（54 万行）做业务诊断。

2. 我做了什么

① 益智玩具调研（做成"情报管道"而非一次性报告）

5 维框架：选品/蓝海、用户评价/需求、竞品/竞店、趋势/季节性、跨平台对比。产出结构化 data.json（可直接喂 Excel / Tableau / BI）+ plotly 可视化报告。设计成可更新、可换品类复用——检索 query 一换就能套到新品类。

② 电商业务健康度（真实数据诊断）

  • 审计：54 万行订单的字段完整性、异常值（Description 26.8% 缺失）核查。
  • 指标：月度 GMV / 订单 / AOV / 复购率 / 取消率 / 退款率。
  • 用户分层：RFM（最近购买 / 频次 / 金额）找出高价值与流失用户。
  • 报告：HTML 自动化报告，结论可直接给业务方。

3. 交付与结果

交付物：能反复用的情报流程（审计→指标→报告一键出）+ 结构化 data.json（BI 就绪）+ plotly 可视化报告 + RFM 用户分层名单。

结果：把"市场感觉"变成可更新、可换品类复用的系统——检索 query 一换就能套到新品类或新数据源。数据诚实：54 万行里 Description 有 26.8% 缺失，先审计再分析，而不是拿脏数据直接出图；FDE 的诊断力建立在"数据可信"上。RFM 分层这种基础动作，价值在于把"高价值用户"从口号变成可触达的名单——进现场就是要拿到能直接用的东西。玩具调研数据来自公开情报（多源口径已标注区间）；零售分析受数据源限流影响，管道已就绪、补更贴近业务的数据源即可套用。

与 FDE 岗位的对应

FDE 能力本项目证据
进现场摸数据（Echo）直接拉真实订单数据 + 公开情报，自己算、自己看
一线诊断用取消率(16%–19%)、退款率、复购率定位生意健康度；RFM 切分可运营分层
部署可运行系统把调研做成"管道"（审计→指标→报告）而非一次性 PPT，换数据源即复用

技术栈：Python 数据处理管道（审计/指标/RFM）、plotly 可视化、BI 就绪的结构化数据（data.json）。
